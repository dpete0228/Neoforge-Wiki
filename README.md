# Superhero Mod Wiki

Heroes, abilities, recipes and quests for the Superhero Mod.

Live page: https://dpete0228.github.io/neoforge-wiki/

This site is generated from the mod's own data files by `tools/wiki/build_wiki.py` in the (private) mod repository, which includes this repository as its `docs/` submodule. Edit the mod, regenerate, then commit and push here.
