How to Join the Server

Everything you need to connect to the Superhero Mod server, split by platform. You need a Microsoft account (the server runs with online-mode on) and you must be whitelisted before you try to join - ask the host to run whitelist add YourUsername first.

Server version: NeoForge 26.3.0.90 for Minecraft 26.3
Mod file: superheromod-0.0.2.jar (ask the host for the download link)
Server address: <your-playit-address>.playit.gg (ask the host for this)
Windows Steam Deck

Windows

  1. Install the official Minecraft Launcher if you don't already have it, and sign in with your Microsoft account.
  2. Download the NeoForge installer for 26.3.0.90 from the NeoForge downloads page - grab the .jar installer, matching Minecraft 26.3.
  3. Run the installer (double-click it; Windows bundles a JRE capable of running it since the Minecraft Launcher already needs Java). Choose "Install client" and leave the default install location.
  4. Open the Minecraft Launcher - a new installation named something like neoforge-26.3.0.90 will appear.
  5. Get superheromod-0.0.2.jar from the host and copy it into: 
    %appdata%\.minecraft\mods
    (paste that path into File Explorer's address bar; create the mods folder if it's missing, or launch the NeoForge profile once first so the launcher creates it for you.)
  6. Launch the neoforge-26.3.0.90 profile from the Minecraft Launcher.
  7. In-game: Multiplayer → Add Server, paste the playit.gg address, and join.

If NeoForge fails to install, make sure Windows has a recent Java runtime - the Minecraft Launcher normally handles this itself, but if you see a Java-version error, install a Temurin JDK 25 build and re-run the installer.

Steam Deck

Assumes nothing is installed except the vanilla Minecraft Flatpak.

  1. Switch to Desktop Mode (hold the Power button → Switch to Desktop).
  2. Open Konsole and find the Flatpak's data folder: 
    flatpak list --app | grep -i minecraft
    Note the app ID it prints (e.g. com.mojang.Minecraft). Its data lives at ~/.var/app/<that-id>/.minecraft.
  3. Install Java 25 with SDKMAN (no root needed): 
    curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install java 25-tem
    Close and reopen Konsole afterwards so java is on your PATH.
  4. Download the NeoForge installer for 26.3.0.90 from the NeoForge downloads page, saved to ~/Downloads.
  5. Run it, pointing the install location at the Flatpak's folder instead of the default: 
    java -jar ~/Downloads/neoforge-26.3.0.90-installer.jar
    Choose "Install client" and change the destination to ~/.var/app/<that-id>/.minecraft.
  6. Add the mod jar: 
    mkdir -p ~/.var/app/<that-id>/.minecraft/mods
cp ~/Downloads/superheromod-0.0.2.jar ~/.var/app/<that-id>/.minecraft/mods/
  7. Open the Flatpak Minecraft Launcher, pick the new 26.3.0.90 profile, sign in with your Microsoft account.
  8. Multiplayer → Add Server → paste the playit.gg address, join.
